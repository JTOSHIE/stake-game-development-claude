# Live wallet 400: the invalid-amount refusal, captured 2026-08-20

**Captured by the OWNER against the live wallet**, per the protocol in this directory's
README. This closes AUDIT_CLOSURE Q6, open since 2026-08-10.

## The request, by shape, with the session redacted

The session token is REPLACED and nothing else is altered. A session token authorises
play against a real balance for as long as its tab lives, so it never enters the record.

| Field | Value |
|---|---|
| Method | `POST` |
| Endpoint | `https://rgsd.stake-engine.com/wallet/play` |
| Origin | `https://we-roll-spinners.live.stake-engine.com` |
| `sessionID` | `<REDACTED>` |
| `mode` | `base` |
| `amount` | `10000000000` micros, which is **10,000.00** display units |

**The amount is deliberately out of range, and the range is the LIVE one.** The
platform's own authenticate response records `"maxBet": 1000000000` for this game, which
is 1,000.00 display units (`docs/records/screenshots/FINDINGS_LEDGER.md`, SA-024, read
off a committed frame of the live payload). The captured request sends **ten times that
ceiling**, so the platform refuses it and **no wager was placed**.

## The response

Status: **HTTP 400**.

Body, exactly as returned:

```json
{"error":"ERR_VAL","message":"invalid amount"}
```

## What this confirms

**The identifier is in a TOP-LEVEL `error` field.** That is the dialect
`frontend/scripts/r045_error_field_proof.mjs` was built for, and its header states the
claim under proof in those words: the platform answers wallet errors with the identifier
in top-level `error`, while `handleRGSError` originally read only a top-level `code` and
so let every real platform error fall through to the generic retryable branch. **The
reader now accepts `code` OR `error`, with `code` winning**, and this body is the first
captured artefact confirming the half it was widened for.

**`ERR_VAL` for an out-of-range amount matches the value the estate already models.**
`frontend/scripts/money_fit_gate.mjs` stubs exactly this refusal at the ladder boundary,
citing an owner confirmation from the R060 close. That stub was a reasonable
reconstruction with nothing captured behind it until now; it is corroborated.

**`message` is a second, human-readable field and the estate does not render it.** The
game shows its own localised banner keyed off the identifier, which is correct: a
platform string in one language cannot be shown to a player in sixteen locales. Recorded
so nobody later reads its presence as an unused opportunity.
