## The two DEFECT rows, both escalated rather than ruled on

Both are player money display, so convention (l.8) applies: this track raises
them with evidence and does not choose the fix.

**SA-021, severity HIGH.** The mini strip cuts the BALANCE with no ellipsis, so
`EUR 479,710.00` renders as `EUR 479`. Measured on the shipped bundle rather than
read off a picture: the element's text is `€479.7K`, `data-fit-mode` `compact`,
`data-fit-px` `9.00` at a floor of 9, `clientWidth` 25 against `scrollWidth` 42,
and `HudOverlay.svelte:989` sets `overflow: hidden` with a comment at `:984`
explaining why there is deliberately no ellipsis. There is no step after
abbreviation, so the box cuts the string in silence.

**TR-066 is not reopened by this and the distinction matters.** At 400 by 225,
the profile Fable's ruling named, the same balance renders whole:
`clientWidth` 50 against `scrollWidth` 50. The cut appears below about 390 css
px. `mini_player_proof.mjs` tests exactly one viewport, so the class it proves
closed is closed at exactly one width. The same fault is visible in another
session's committed frame from the night before, where `EUR 512.29` renders as
`EUR 512.2`, which is the more dangerous form because nothing about it looks cut.

**SA-022, severity HIGH.** `WinPod.svelte:6` renders player money as
`$winAmount.toFixed(2)`. That is the only money `.toFixed` left anywhere in
`frontend/src`; every other occurrence in the tree is a CSS transform or a data
attribute. It carries no separators, no currency symbol and no platform display
metadata, and its zone is a fixed `width: 99px` with `white-space: nowrap` and no
fit action, coordinates commented "from Manus QC". A `EUR 3,750,000.00` win
renders as `3750000.00` and overflows the plate, beside a `MEGA WIN!!!` banner
that formats correctly through `formatBalance` in the same frame.

`WinPod` has one consumer, `ReplayMode.svelte:290`. It renders in **Bet Replay
and nowhere else**, which is a mandatory platform surface a reviewer opens
deliberately, on a large bet, which is exactly the input that overflows.
